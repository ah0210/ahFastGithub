# 主题：Windows 安装包方案评估

时间：2026-05-15 20:38
参与方：用户
状态：进行中
标签：打包, 安装包, Windows, 商业化

---

## 讨论背景

FastGithub 已完成安全性增强、UI 优化和许可证变更，版本更新至 2.4.1。为支持商业分发，需要制作专业的 Windows 安装包，替代当前的绿色压缩包发布方式。

当前项目结构：
- 主程序：`FastGithub.Server` (.NET 10)
- UI 界面：`FastGithub.UI` (WPF, .NET 10)
- 发布脚本：`publish-windows-only.cmd`
- 许可证：商业许可证（非 MIT）

---

## 讨论要点

- [ ] 方案选型：Inno Setup vs WiX vs dotnet-msix vs NSIS
- [ ] 安装包功能需求：CA 证书自动安装、服务注册、开机自启、卸载清理
- [ ] 商业分发要求：数字签名、版本管理、升级机制
- [ ] 开发成本与维护成本评估
- [ ] 用户体验：安装向导、静默安装、企业部署支持

---

## 决策结论

- **核心需求确认**：安装包需自动安装 CA 证书到 CurrentUser\Root 存储，并注册 FastGithub.Server 为 Windows 服务
- **方案倾向**：待用户确认
- **打包问题修复**：托盘图标因外部文件未正确复制到发布目录而丢失，已改为嵌入程序集资源 (`EmbeddedResource`)，彻底解决打包后图标消失问题
